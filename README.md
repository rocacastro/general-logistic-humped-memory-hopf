# General logistic growth in humped-memory predator-prey models

This repository contains the Python scripts, numerical data, and generated figures associated with a study of Hopf bifurcations in predator-prey models with general logistic prey growth and humped memory.

The repository is intended for reproducibility. It does **not** include the manuscript source files.

## Repository structure

```text
general-logistic-humped-memory-hopf/
├── README.md
├── LICENSE
├── CITATION.cff
├── requirements.txt
├── .gitignore
├── scripts/
├── data/
│   ├── raw/
│   └── generated/
└── figures/
```

## Contents

### scripts/

The folder `scripts/` contains the Python scripts used to generate the numerical results and figures.

Expected scripts:

```text
00_memory_kernels_comparison_en.py
01_hopf_constants_table_en.py
02_hyperlogistic_bifurcation_diagram_en.py
06_floquet_multipliers_hyperlogistic_en.py
08_applied_control_theta2_clear_figure_fixed.py
09_applied_control_theta2_floquet.py
```

### data/

The folder `data/` contains raw and generated data.

- `data/raw/` contains the greenhouse counts transcribed from the published source cited in the manuscript.
- `data/generated/` is reserved for numerical data generated by the Python scripts.

### figures/

The folder `figures/` contains the generated figures in PDF and PNG formats.

## Installation

The scripts require Python 3.10 or later.

To install the required packages, run:

```bash
pip install -r requirements.txt
```

The main required packages are:

```text
numpy
scipy
matplotlib
pandas
```

## Reproducing the results

From the root folder of the repository, run the scripts individually. For example:

```bash
python scripts/00_memory_kernels_comparison_en.py
python scripts/01_hopf_constants_table_en.py
python scripts/02_hyperlogistic_bifurcation_diagram_en.py
python scripts/06_floquet_multipliers_hyperlogistic_en.py
python scripts/08_applied_control_theta2_clear_figure_fixed.py
python scripts/09_applied_control_theta2_floquet.py
```

The scripts generate figures and numerical data associated with:

- the comparison between exponential memory and humped memory;
- Hopf thresholds for several logistic growth functions;
- the local bifurcation diagram in the hyperlogistic case;
- Floquet multipliers for the hyperlogistic periodic orbit;
- the applied greenhouse biological-control scenario with `f(n)=1-n^2`;
- Floquet multipliers for the applied scenario.

## Data note

The repository does not contain new experimental data. The greenhouse counts in `data/raw/` are transcribed from a published greenhouse experiment cited in the manuscript. All other numerical data are generated computationally from the model equations and parameter values reported in the manuscript.

## Manuscript note

The manuscript source files are intentionally not included in this repository. The repository contains only code, data, and generated figures needed for reproducibility.
