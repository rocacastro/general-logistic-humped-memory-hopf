# Data

This folder contains the data used in the numerical part of the article.

## Folder structure

```text
data/
├── raw/
│   └── greenhouse_counts_alpysbayeva2024.csv
├── generated/
└── README_data.md
```

## raw/

The file `greenhouse_counts_alpysbayeva2024.csv` contains the greenhouse counts of *Tetranychus urticae* used in the data-informed biological-control scenario.

The variables are:

- `treatment`: experimental treatment.
- `time_days`: time in days.
- `T_urticae_count_per_linear_meter`: count of *Tetranychus urticae* per linear meter.

The values are taken from the published greenhouse experiment cited in the manuscript.

## generated/

This folder is intended for numerical data generated by the Python scripts in the `scripts/` folder.

The generated files may include:

```text
hopf_constants_table.csv
bifurcation_extrema_hyperlogistic_en.csv
floquet_multipliers_hyperlogistic_en.csv
periodic_orbit_hyperlogistic_en.csv
applied_theta2_long_trajectory.csv
applied_theta2_floquet_multipliers.csv
applied_theta2_periodic_orbit.csv
```

These files can be reproduced by running the scripts provided in the repository.

## Notes

The repository does not contain new experimental data. The greenhouse counts in `raw/` are transcribed from a published source cited in the manuscript. All other numerical data are generated computationally from the model equations and parameter values reported in the manuscript.
