# Figures

This folder contains the figures generated by the Python scripts in the `scripts/` folder.

## Main manuscript figures

- `memory_kernels_comparison_en.pdf` / `.png`: comparison between exponential memory and humped memory.
- `applied_control_theta2_orbit_clear_en.pdf` / `.png`: data-informed greenhouse biological-control scenario with `f(n)=1-n^2`.
- `bifurcation_diagram_a_hyperlogistic_en.pdf` / `.png`: local bifurcation diagram for the hyperlogistic case.
- `floquet_multipliers_hyperlogistic_en.pdf` / `.png`: Floquet multipliers for a stable periodic orbit in the hyperlogistic case.

## Additional reproducibility figure

- `floquet_multipliers_applied_theta2_en.pdf` / `.png`: Floquet multipliers for the applied greenhouse scenario.

The PDF files are intended for manuscript inclusion. The PNG files are included for quick preview.
